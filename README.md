## The fortune

> Your future self is already fixing the shortcut you are about to take.

70 characters. One original line of fortune-cookie wisdom for a software
developer, in the voice of a tired senior engineer: a prediction about
the reader's own future, built on the daily truth that every shortcut
taken today becomes tomorrow's debugging session — and the person who
pays for it is you, later. The quiet twist is the tense: your future
self is not going to fix it, they are already fixing it, because the
shortcut is being taken right now.

## How it works

`main.py` writes the fortune — exactly one line, no trailing newline —
to `/output/entry.txt` (or `$ENTRY_OUT` when set) and prints it to
stdout. The gate requires UTF-8 text of 1–120 characters, not only
whitespace; this entry is 70 characters.

Run it:

```sh
python3 main.py
```
